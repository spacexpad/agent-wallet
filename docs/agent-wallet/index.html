A keyless wallet your agent can sign with.

Privy creates the wallets and holds the keys for Solana, Ethereum, Base, and BNB Chain. You sign in with email or Google, bind an agent, and decide what that agent may sign. There is no seed phrase and no private-key export.

Install, sign in, bind

  1. Add the extension

    Install from the Chrome Web Store listing above. The item name is SpaceXpad agent wallet, version 0.1.0. Match the extension ID before you trust a copy.

  2. Sign in

    Open the toolbar popup. Use Email, then Send code and Confirm code. Or choose Continue with Google. Google sign-in opens its own window. The popup also offers 简体中文 and 繁體中文. Privy creates the embedded wallets. The extension never asks for a seed phrase.

  3. Bind an agent

    The wallet stays closed until an agent is bound. There is no skip. On Bind an agent, choose Copy prompt and give that note to the agent. It includes a PAIR_CODE that expires in 30 minutes. The agent calls spacexpad_pair and shows a token that starts with spx_bind_. Paste it into Binding token and choose Bind.

    Install the MCP server on the agent’s own computer first. Use your computer only when that agent has no runtime of its own. Set SPACEXPAD_AUTH_URL to the authorization service the extension already uses.

    SPACEXPAD_AUTH_URL=https://spacexpad-agent-wallet-auth.timmy2048.workers.dev

    A missing or different value will not match the binding token. The setup document has the command and the client configuration. Do not paste a bridge token into Settings.

What the wallet holds

Solana
Its own address.
Ethereum, Base, and BNB Chain
One shared EVM address.

The popup shows mainnet balances by default. A failed read stays an error. It is not shown as zero. Agent tools use mainnet unless the request names devnet or testnet. Solana test traffic is devnet. Ethereum and Base testnet is Sepolia. BNB Chain testnet is BSC testnet.

A bound agent can read balances, sign, and send inside the permissions you granted, with no confirmation click. After you sign in and bind an agent, offline signing is on, so that can continue while Chrome is closed. Privy still holds the keys. The extension does not receive a seed or an exported private key.

The SpaceXpad launchpad is a separate product and is still on Solana devnet. This extension does not make that site a mainnet launchpad.

Chrome Web Store version 0.1.0 does not include custom RPC endpoints.

Pause, revoke, and the default

A bound agent signs and sends on its own, inside what you granted. Offline signing and full access are both the default. That is the risk until you change them.

Full access
Default, under Settings, then Risk policy. Sign and send have no USD cap. An empty whitelist does not block signing. Choose Enforce USD limits on that same screen to set a single-transaction cap and a daily cap. If a limit is on and a price is missing, the extension refuses the signature. It does not invent a transaction hash.
Pause all agents
Settings, then Risk policy. Signing and sending stop for every agent. Balance reads still work. The popup says “Agents are paused.” Resume is on that line and on the same Risk policy control.
Turn off offline signing
Agent tab, on the bound agent. Use this when you do not want sign and send while Chrome is closed. Turn on offline signing is the control that grants it again.
Remove
Agent tab, on that agent’s row. The binding is revoked. An unbound, removed, or paused request is rejected and nothing is signed.
